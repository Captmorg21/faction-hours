DEPLOYING CHANGES
=========================================================================

Run scp from WINDOWS (prompt reads C:\Users\Jack>), never from the server.
If you see "Could not resolve hostname c" you're in the wrong terminal.

Website only (no restart needed, just Ctrl+F5 in the browser):
  scp C:\Users\Jack\Downloads\faction-hours.html jack@194.164.29.81:/var/www/faction/index.html

Server code (two steps, because /opt needs root):
  scp C:\Users\Jack\Downloads\server.js jack@194.164.29.81:/tmp/server.js
then on the server:
  sudo mv /tmp/server.js /opt/faction-hours/server.js
  sudo systemctl restart faction-hours

Check it came back up:
  sudo journalctl -u faction-hours -n 15 --no-pager

Want to see: "Faction Hours API listening", "roster refreshed", "NFL week N".

=========================================================================
SECRETS
=========================================================================

  sudo cat /etc/faction-hours.env                    view (root only)
  sudo nano /etc/faction-hours.env                   edit, then restart service

What's in it:
  JOIN_PASS       faction passphrase for sending hours without a key
  ADMIN_KEY       shared admin key, the break-glass way in
  TORN_KEY        your Torn Public API key, used for roster and wars
  ADMIN_IDS       player IDs that always get admin (comma separated)
  NFL_ENFORCERS   who administers the pillow forfeit

Generate a new random secret:
  openssl rand -base64 24

NOTE: 'source /etc/faction-hours.env' fails as jack - the file is root only.
Use this shape instead:
  sudo bash -c 'source /etc/faction-hours.env; curl -s "https://api.torn.com/faction/?selections=basic&key=$TORN_KEY"' | head -c 300

SECURITY
=========================================================================

  sudo ufw status                                    firewall rules
  sudo ufw allow 443/tcp                             open a port
  sudo lastlog                                       last login per user
  sudo journalctl -u ssh --since today --no-pager    ssh attempts

Ports open: 22 (ssh), 80 (http), 443 (https). Password login is off;
only your key works. Root can't log in remotely.


=========================================================================
WHEN SOMETHING'S BROKEN
=========================================================================

Site won't load at all
  sudo systemctl status caddy --no-pager
  sudo journalctl -u caddy -n 30 --no-pager

Site loads but tabs are empty / "can't reach the server"
  sudo systemctl status faction-hours --no-pager
  curl localhost:3000/api/roster
  If that works but the site doesn't, it's the Caddyfile proxy section.

Service won't start
  sudo journalctl -u faction-hours -n 30 --no-pager
  Usually a missing value in /etc/faction-hours.env - it refuses to start
  without JOIN_PASS, ADMIN_KEY and TORN_KEY.

Admin rights not working
  sudo journalctl -u faction-hours -n 20 --no-pager | grep -i admin
  Look for "Always-admin player IDs:". Missing means ADMIN_IDS isn't set.
  Sign out on the site and back in after changing it.

Changes not showing
  Ctrl+F5 to hard refresh. Then check the file actually landed:
  ls -la /var/www/faction/    and    ls -la /opt/faction-hours/
  A timestamp older than your upload means the scp went elsewhere.


=========================================================================
NANO, SINCE IT CATCHES EVERYONE
=========================================================================

nano only has the file open once the screen CHANGES and you see
"GNU nano" at the top. If you can still see jack@ubuntu:~$ then it
isn't open and whatever you type is going to the shell instead.

  Ctrl+O then Enter     save
  Ctrl+X                exit
  Ctrl+K                cut the current line (press repeatedly to clear)
  Ctrl+W                search

Avoid ! in passwords typed at the shell prompt - bash treats it specially.
